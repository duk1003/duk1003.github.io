이 글에서는 챕터2, Words and Tokens에 대해 설명하겠습니다. 여기서는 기본적으로 NLP 모델이 사람이 하는 말을 알아들을 수 있도록 하기 위한 방법들에 대해서 설명하고 있습니다. 모델이 사람이 하는 말, 즉 Raw text를 입력으로 받으면 이를 이해하기 위해 Regular Expression, 줄여서 Rerex로 바꾸고, 이를 Tokenizer 시켜야 모델이 이해할 수 있는 형태로 바뀌게 됩니다. 따라서, Regex가 무엇인지 알아본 뒤, Text Normalizer와 Tokenzier를 만들어보고 마지막으로, 두 문자열이 얼마나 다른지 계산하는 Minimum Edit Distance 알고리즘을 공부하겠습니다.

가장 먼저, 정규표현식은 텍스트 전처리에서 아주 유용한 도구로 긴 텍스트에서 패턴을 파악할 때 사용됩니다. 정규표현식을 위해 사용되는 문법들을 설명하겠습니다. 
```
.           : 한 개의 임의의 문자
?           : 앞의 문자가 0개 혹은 1개 존재
*           : 앞의 문자가 0개 이상 존재
+	        : 앞의 문자가 1개 이상 존재
^	        : 뒤의 문자열로 문자열이 시작
$           : 앞의 문자열로 문자열이 끝남
{숫자}       : 숫자만큼 반복함
{숫자,}	     : 숫자 이상 만큼 반복함
[]	        : 대괄호 안의 문자들 중 한 개의 문자와 매치
[^문자]	     : 해당 문자를 제외한 문자를 매치
|	        : 논리연산자(OR)
\\\	        : 역슬래시 문자
\\d	        : 모든 숫자([0-9])
\\D	        : 숫자를 제외한 모든 문자([^0-9])
\\s	        : 공백([\t\n\r\f\v])
\\S	        : 공백을 제외한 문자([^\t\n\r\f\v])
\\w	        : 문자 또는 숫자([a-zA-Z0-9])
\\W	        : 문자 또는 숫자가 아닌 문자([^a-zA-Z0-9])
```

그리고 파이썬에서는 이러한 정규표현식을 지원하는 모듈 re가 있습니다. 여기서는 문자열에서 정규표현식을 쉽게 찾을 수 있게끔 하는 여러 함수들을 지원하고 있습니다.
```
re.compile()	: 정규표현식을 컴파일하는 함수
re.search()	    : 문자열 전체에 대해 정규표현식과 매치되는지를 검색하는 함수
re.match()	    : 문자열 처음이 정규표현식과 매치되는지 검색하는 함수
re.split()	    : 정규표현식을 기준으로 문자열을 분리하여 리스트로 리턴하는 함수
re.findall()	: 문자열에서 정규표현식과 매치되는 모든 경우의 문자열을 찾아 리스트로 리턴하는 함수
re.sub()	    : 문자열에서 정규표현식과 일치하는 부분에 대해 다른 문자열로 대체하는 함수
```

아래는 regex를 이용해 문자열에서 전화번호를 추출하는 예시 코드입니다. 대부분은 앞에서 설명한 문법들이지만, 몇 가지 추가되는 내용들이 있습니다. (?<!\d)는 부정형 후방 탐색으로 현재 위치 바로 앞에 숫자가 없어야 한다는 의미를 가지고 있습니다. 마찬가지로 (?!\d)는 부정형 전방 탐색으로 현재 위치 바로 다음 문자가 숫자가 아니어야 한다는 의미를 가지고 있습니다. 이 두 구문을 앞뒤로 둬서 전화번호 패턴 앞뒤에 바로 붙은 숫자가 있는 경우를 제외하고 있습니다. 마지막으로 (?:...)은 비캡처 그룹을 만드는 문법으로 괄호 안의 패턴을 하나로 묶지만, 매칭 결과를 별도의 그룹으로 저장하지 않습니다.
```
import re

def extract_phone_numbers(text: str) -> list[str]:
    pattern = (
        r"(?<!\d)"
        r"(?:01[016789]|02|0[3-6][1-5])"
        r"[-\s]?\d{3,4}[-\s]?\d{4}"
        r"(?!\d)"
    )
    phone_numbers = re.findall(pattern, text)

    return [re.sub(r"[-\s]", "", phone_number) for phone_number in phone_numbers]

text = """
연락처는 010-1234-5678입니다.
회사 전화는 02 123 4567입니다.
지점 전화는 031-123-4567입니다.
구분자가 없는 번호는 01098765432입니다.
"""

phone_numbers = extract_phone_numbers(text)
for phone_number in phone_numbers:
    print(phone_number)
```
