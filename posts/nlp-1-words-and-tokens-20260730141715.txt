이 글에서는 챕터2, Words and Tokens에 대해 설명하겠습니다. 여기서는 기본적으로 NLP 모델이 사람이 하는 말을 알아들을 수 있도록 하기 위한 방법들에 대해서 설명하고 있습니다. 모델이 사람이 하는 말, 즉 Raw text를 입력으로 받으면 이를 이해하기 위해 Regular Expression, 줄여서 Rerex로 바꾸고, 이를 Tokenizer 시켜야 모델이 이해할 수 있는 형태로 바뀌게 됩니다. 따라서, Regex가 무엇인지 알아본 뒤, Text Normalizer와 Tokenzier를 만들어보고 마지막으로, 두 문자열이 얼마나 다른지 계산하는 Minimum Edit Distance 알고리즘을 공부하겠습니다.

그리고 파이썬에서는 이러한 정규표현식을 지원하는 모듈 re가 있습니다. 여기서는 문자열에서 정규표현식을 쉽게 찾을 수 있게끔 하는 여러 함수들을 지원하고 있습니다.

re.match()		: 문자열 처음이 정규표현식과 매치되는지 검색하는 함수

아래는 regex를 이용해 문자열에서 전화번호를 추출하는 예시 코드입니다. 대부분은 앞에서 설명한 문법들이지만, 몇 가지 추가되는 내용들이 있습니다. (?<!\d)는 부정형 후방 탐색으로 현재 위치 바로 앞에 숫자가 없어야 한다는 의미를 가지고 있습니다. 마찬가지로 (?!\d)는 부정형 전방 탐색으로 현재 위치 바로 다음 문자가 숫자가 아니어야 한다는 의미를 가지고 있습니다. 이 두 구문을 앞뒤로 둬서 전화번호 패턴 앞뒤에 바로 붙은 숫자가 있는 경우를 제외하고 있습니다. 마지막으로 (?:...)은 비캡처 그룹을 만드는 문법으로 괄호 안의 패턴을 하나로 묶지만, 매칭 결과를 별도의 그룹으로 저장하지 않습니다.
```
import re

def extract_phone_numbers(text: str) -> list[str]:
    pattern = (
        r"(?<!\d)"
        r"(?:01[016789]|02|0[3-6][1-5])"
        r"[-\s]?\d{3,4}[-\s]?\d{4}"
        r"(?!\d)"
    )
    phone_numbers = re.findall(pattern, text)

    return [re.sub(r"[-\s]", "", phone_number) for phone_number in phone_numbers]

text = """
연락처는 010-1234-5678입니다.
회사 전화는 02 123 4567입니다.
지점 전화는 031-123-4567입니다.
구분자가 없는 번호는 01098765432입니다.
"""

phone_numbers = extract_phone_numbers(text)
for phone_number in phone_numbers:
    print(phone_number)
```

다음으로는 토큰화에 대해 알아보겠습니다. 텍스트를 학습시킬 때, 주의할 점들이 있습니다. 단순히 텍스트를 단어 단위로 쪼개는 것은 corpus에 없는 단어가 들어오는 경우를 대처하기 어렵습니다. 또한, 몇몇 언어들은 띄어쓰기가 없거나 I'm처럼 보이는 그대로가 아닌 변환해야 하는 경우들을 가지고 있습니다. 나아가, 같은 단어인데 대소문자 차이로 다른 단어로 인식되거나 고유명사 등등 텍스트를 학습하기 위해서는 많은 전처리 과정들이 요구됩니다. 그래서 text Normalization과 subword tokenization을 거치게 됩니다. 대표적인 text normalization을 살펴보면 대소문자 통일, 불필요한 공백 제거, 특수문자 정규화, Unicode 정규화, 숫자 정규화, 축약형 정규화, stemming(단어에서 접사를 제거해 어간 비슷한 형태를 얻는 방법), lemmatization(사전에 존재하는 기본형으로 변환) 등이 있습니다. 하지만, 정규화 과정에서 주의할 점은 만들고자 하는 모델의 목표나 적용하고자 하는 언어 등에 따라 상황에 맞는 정규화를 사용해야 한다는 것입니다. 

다음으로 subword tokenization을 위해서 Byte-Pair Encoding을 사용합니다. 이 알고리즘은 가장 먼저 문장을 단어 단위로 쪼갠 뒤, 각 단어에서 인접한 문자 쌍의 빈도를 계산합니다. 그 이후, 정해진 merge 횟수 동안 가장 빈도가 높은 쌍을 병합하는 과정을 반복합니다. 그렇게 만들어진 subword 사전을 만들어 입력으로 들어오는 단어들을 subword의 조합으로 인식합니다. 예를 들면, "set new new renew reset renew"과 같은 문장이 들어오면 먼저 new 2개, set 1개, renew 2개, reset 1개로 쪼개집니다. 그리고 빈도가 높은 쌍부터 병합되어 ne, new, re, renew, se, ... 순서대로 subword에 포함됩니다. 이렇게 생성된 사전을 통해 새롭게 들어오는 단어를 쪼개, 그 의미를 유추하게 됩니다. 아래는 BPE를 간략하게 구현한 예시 코드입니다.
```
from collections import Counter

def get_pair_frequencies(vocabulary: dict[tuple[str, ...], int]) -> Counter:
    pair_frequencies = Counter()
    for symbols, frequency in vocabulary.items():
        for index in range(len(symbols) - 1):
            pair = (symbols[index], symbols[index + 1])
            pair_frequencies[pair] += frequency
    return pair_frequencies


def merge_pair( vocabulary: dict[tuple[str, ...], int], pair_to_merge: tuple[str, str]) -> dict[tuple[str, ...], int]:
    merged_vocabulary = {}
    first, second = pair_to_merge
    merged_symbol = first + second
    for symbols, frequency in vocabulary.items():
        new_symbols = []
        index = 0
        while index < len(symbols):
            if (index < len(symbols) - 1 and symbols[index] == first and symbols[index + 1] == second):
                new_symbols.append(merged_symbol)
                index += 2
            else:
                new_symbols.append(symbols[index])
                index += 1
        merged_vocabulary[tuple(new_symbols)] = frequency
    return merged_vocabulary


def train_bpe(word_frequencies: dict[str, int], num_merges: int) -> tuple[dict[tuple[str, ...], int], list[tuple[str, str]]]:
    vocabulary = { tuple(word): frequency for word, frequency in word_frequencies.items() }
    merge_rules = []
    for _ in range(num_merges):
        pair_frequencies = get_pair_frequencies(vocabulary)
        if not pair_frequencies: break
        best_pair = pair_frequencies.most_common(1)[0][0]
        merge_rules.append(best_pair)
        vocabulary = merge_pair(vocabulary, best_pair)
    return vocabulary, merge_rules

word_frequencies = {
    "new": 2,
    "renew": 2,
    "set": 1,
    "reset": 1,
}
vocabulary, merge_rules = train_bpe(word_frequencies, num_merges=6)
print("Merge rules:")
for rule in merge_rules: print(rule)
print("\nFinal vocabulary:")
for symbols, frequency in vocabulary.items(): print(symbols, ": ", frequency)
```

마지막으로는 Minimum Edit Distance에 대해 알아보겠습니다. 이 알고리즘은 두 단어나 문자열이 얼마나 유사한지 비교하는 방법입니다. 두 문자가 있을 때, 삽입, 삭제, 치환을 통해 변환하는데 필요한 최소 편집 작업 수를 기준으로 얼마나 유사한지 판단합니다. 예를 들면, cat을 cut으로 바꾸기 위해서는 a를 u로 한 번 치환하면 되므로 거리는 1이 됩니다. 아래는 해당 알고리즘을 구현한 코드로 DP를 이용해 최소 편집 거리를 알 수 있습니다. 
```
def minimum_edit_distance(source: str, target: str) -> int:
    rows = len(source) + 1
    columns = len(target) + 1
    distance = [[0] * columns for _ in range(rows)]
    # source를 빈 문자열로 만드는 삭제 비용
    for i in range(rows): distance[i][0] = i
    # 빈 문자열을 target으로 만드는 삽입 비용
    for j in range(columns): distance[0][j] = j
    for i in range(1, rows):
        for j in range(1, columns):
            substitution_cost = (0 if source[i - 1] == target[j - 1] else 1)
            deletion = distance[i - 1][j] + 1
            insertion = distance[i][j - 1] + 1
            substitution = (distance[i - 1][j - 1] + substitution_cost)
            distance[i][j] = min(deletion, insertion, substitution,)
    return distance[-1][-1]

print(minimum_edit_distance("cat", "cut"))
print(minimum_edit_distance("intention", "execution"))
```
